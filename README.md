# Labs de ciberseguridad

Wiki con los laboratorios de seguridad defensiva que he resuelto y documentado paso a paso: análisis de tráfico, investigación de malware, inteligencia de amenazas y OSINT.

**Léela aquí:** https://marinogscs.github.io/wiki-labs

Los labs se escriben en Obsidian y se publican con [Quartz](https://quartz.jzhao.xyz). Para actualizar la wiki:

```bash
./publicar.sh          # copia los labs, compila y sube a GitHub
./publicar.sh --local  # vista previa en http://localhost:8080
```
